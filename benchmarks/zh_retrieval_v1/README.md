# 中文检索基准 v1（Phase 6）

数据：`dataset.json`，**19 篇合成文档、20 个问题**，16 有答案、4 无答案、4 个问题需要多篇资料。文档与问题均由开发助手依据本项目架构手工编写，供人工逐条检查；没有独立人工复审，不能称为人工认证的真实业务测试集。未使用 P1/P2/P3 数据或真实企业材料。

每题的 `relevant_documents` 与 `rationale` 是事先规定的文档级二元标注。多文档问题要求找齐全部金标资料；同主题但不能支持所问事实的不算相关。正文含明确“合成测试材料”标识，D18/D19 是干扰文档，D16 含只供测试的攻击串。

## 冻结与口径

在第一次检索前冻结，SHA256：

```text
6b7975eb701d461fd712cef3acc0ab749d42498eca65fb75f67250be46d5475c
```

`dataset.sha256` 和自动化测试固定该值。没有根据检索结果修改问题、文档、答案或金标，也没有调阈值、换模型、加查询前缀或增加第二套数据库。

每篇文档经真实 tokenizer 导入后恰好一个片段，稳定测试 ID 为 `D01#0` 等；实际数据库 UUID 由导入生成。评测通过数据库 chunk_id 映射回固定文档 ID，不能靠标题猜测相关性。最终结果同时记录实际 locator、document_id、chunk_id、source_ref、分数及该次结果的 S#。S# 是查询结果内的编号，不是跨问题全局文档 ID。

- Recall@k：对 16 个有答案问题，计算 top-k 中命中的不同金标文档数 / 该题金标文档总数，再宏平均。不是只要命中一篇就算召回成功。
- MRR@5：对同样 16 题，取第一个相关文档名次的倒数，未命中为零。它不证明多文档证据完整，另报全金标覆盖。
- 无答案 4 题不进入 Recall/MRR 分母，单独报告零结果拒答率和非空候选数。非空候选不等于生成了答案。
- 正式口径调用真实 `PgVectorSearch.search(limit=5)`，保留默认分数阈值 0.5；额外记录无阈值 SQL top-5，仅作排序诊断。本次两者相同。
- 模型、索引、查询编码和阈值均为原有配置。五个模型文件的 SHA256 及包版本见 JSON。余弦分数不是答案正确概率。

## 真实失败与局限

Q01 的断电续跑问题把电影干扰 D19 排第一；Q07 分片问题也如此。Q03/Q09/Q13 只取回部分金标，Q05 连一篇金标也没找到。包含英文技术关键词的问题如 Q04/Q06/Q11/Q12 相对容易，但本小集没有证明这种相关性的因果机制。

模型面向英文。39 段输入（19 正文 + 20 查询）共 2473 个无特殊 token 的编码 token，其中 1682 个为 `[UNK]`（68.0146%）。这支持当前模型中文表示能力不足的担忧，但不是单独的因果实验。四个无答案问题的首位分数约为 0.7323、0.7482、0.7844、0.6873，均高于 0.5，不能把高分当作可回答性。

真实图诊断中，无答案 Q19 仍产生 5 个来源并走 `assess:sufficient`，Mock 报告状态为 completed。这只意味着流程与语法检查结束；来源数量门槛没有识别语义不充分。没有测量真实 LLM 报告准确率。

## 复现与原始记录

先按 DEVELOPMENT.md 安装锁定依赖、准备现有本地模型缓存、启动专用 PostgreSQL。脚本只创建随机名称的隔离 collection，结束清理自己的数据库行，不修改既有索引。

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_zh_retrieval.py --label rerun --output data/phase6/rerun.json
.\.venv\Scripts\python.exe -m pytest -q tests/test_phase6_zh.py tests/test_pgvector_integration.py
```

可用 `RESEARCH_TEST_POSTGRES_DSN` 指向另一专用测试库，禁止连接业务库。脚本拒绝覆盖已有输出。

- `results/baseline.json`：原 Phase 5 实现的完整逐题基线，未改写。
- `results/baseline-regressions.xml`：修复前两个确实失败的回归测试（元数据与尾部）。
- `results/phase6.json`：初次完整性修复后测量，保留中间运行。
- `results/final.json`：最终可审查记录，含真实来源映射及无答案图诊断。

本集规模小、合成、主题集中，未独立人工复审，也没有开发集/盲测集划分。它是诊断基准，不是生产分布或跨模型泛化证明。检索 Recall/MRR、引用合法性与最终报告准确率必须分别陈述。
